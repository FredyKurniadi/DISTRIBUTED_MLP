# Installation

## Prasyarat
- Windows PowerShell
- Python 3.9+

## Versi Python Digunakan
- Versi yang digunakan pada environment lokal proyek ini: Python 3.9.13

## Setup
Dari folder `DISTRIBUTED_MLP` jalankan:

```powershell
.\scripts\setup_all.ps1
```

Script ini membuat virtual environment di:
- `.venv` (di dalam folder DISTRIBUTED_MLP)

Dan menginstal dependency dari `requirements.txt`.
